# Lumina — a TV home screen for a rooted LG webOS TV

**Lumina** (`com.shashvat.launcher`) is a custom home screen for a rooted **LG 43NU885BPLA** (webOS 26),
plus the root, debug and de-bloat tooling that grew around it: a boot autostart, a Home-key
rebind, a watchdog that bounces LG's own home back to Lumina, and a small speed/privacy stack.

The TV is rooted via [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel);
everything here is installed and driven over the LAN (telnet/SSH/luna-send, SSAP, and the TV's
Chrome DevTools port). **No firmware is flashed and nothing is downgraded.**

## What's here

| Path | What it is |
| --- | --- |
| `app/` | The launcher itself: plain HTML/CSS/ES5, **no build step**. `index.html`, `css/`, `js/`, `fonts/`, `assets/` (bundled posters), `appinfo.json`. |
| `app/js/data.js` | The data layer: live rails from Stremio's public **Cinemeta** catalogues, live search, per-title meta (cast/director), My List + Continue Watching in `localStorage`, and **JustWatch (India)** "where to watch" offers. |
| `app/js/apps.js` | The **generated** app list (baked at deploy time, see below). Regenerated by `tools/fetch_apps.py`. |
| `app/js/fallback.json` | Bundled offline catalogue used when the network (or Cinemeta) is unavailable. |
| `design/lumina-reference.html` | The original **Open Design prototype** the launcher's layout and styling came from. Kept as a labelled reference, not shipped. |
| `tools/` | Build, deploy, debug: `tvsh.py`, `probe_tv.py`, `fetch_apps.py`, `build_ipk.py`, `inspect_ipk.py`, `deploy.py`, `ssap_install.py`, `launch_app.py`, `glasshouse_services.py`, `tv-cdp.js`, and helpers. |
| `rootrun/` | The root-side payload scripts: `lumina-boot.sh` (one-shot boot launch), `lumina-watchdog.sh` (foreground-app watchdog) and the earlier `autoroot.sh` payloads. |
| `dist/` | On-TV deployment helpers (`tv_update.sh`, `tv_install.sh`, `tv_lumina_install.sh`, `tv_icons.sh`, `tv_push.sh`, `tv_stop_launcher.sh`, `tv_unroot.sh`, `tv_wifi_revert.sh`) plus build output. **The built `.ipk` files are gitignored** — only the `.sh` helpers are committed. |

`glasshouse/` (a vendored checkout of the upstream Glasshouse project) and `shots/` are gitignored.

## The launcher

- **Titles** come live from Cinemeta with no account: `https://cinemeta-catalogs.strem.io/top`
  for the rails (Popular Movies, Popular Series, Top Rated, Action, Comedy, Sci-Fi, Thriller,
  Drama Series) and `https://v3-cinemeta.strem.io/meta` for full meta. Rails are cached in
  `localStorage` for 6 h; a bundled fallback catalogue covers offline use.
- **Hero**, **detail panel** per title (year/rating/runtime/genre chips, synopsis, cast,
  director, Trailer + Web-page buttons), **live search**, an **Apps** tab, and a profile menu.
- **My List** and **Continue Watching** are `localStorage`-only (`lumina.list`, `lumina.continue`) —
  everything we've seen is retained so the lists still render after the rails change.
- **Play** launches **Stremio** (`io.strem.webos`) and asks you to pick a source there; there is no
  bundled player. Trailer opens a YouTube search; Web page opens IMDb in the TV browser.
- **Where to watch**: per-title offers from JustWatch's GraphQL API (`country: IN`), cached 24 h,
  filtered to services actually installed, rendered as hand-off chips (Prime Video, Netflix,
  JioHotstar, Apple TV, SonyLIV, ZEE5, YouTube) that launch the provider app with its own deep
  link/ID. **Best-effort** — some apps ignore deep links and land on their home screen.
- **App list + icons are baked, not queried**: webOS denies `listApps` to third-party apps, so
  `tools/fetch_apps.py` reads the installed apps over SSAP and writes `app/js/apps.js` plus an
  icon-copy manifest (`rootrun/copy_icons.sh` / `dist/copy_icons.sh`). Icons live inside the TV's
  app folders (and aren't fetchable remotely), so the manifest copies them on-device, falling back
  to each app's own resource URL.

## Build

The app is plain files — nothing to compile. To package:

```sh
python3 tools/build_ipk.py          # -> dist/com.shashvat.launcher_<version>_all.ipk
python3 tools/inspect_ipk.py dist/com.shashvat.launcher_0.2.2_all.ipk   # verify control + appinfo
```

`build_ipk.py` writes a webOS `.ipk` (an `ar` archive wrapping `control.tar.gz` + `data.tar.gz`)
straight from `app/`, with no external dependencies. Bump `app/appinfo.json`'s `version` (currently
`0.2.2`) before building.

## Deploy

Dev installs need the dev-mode flag and a restarted installer, or they fail silently:

```
mkdir -p /var/luna/preferences/devmode_enabled ; restart appinstalld
```

From the Mac, either:

- `python3 tools/deploy.py dist/com.shashvat.launcher_0.2.2_all.ipk --launch com.shashvat.launcher`
  — serves the IPK from a local HTTP server and installs it over the Homebrew Channel's SSAP service; or
- `python3 tools/ssap_install.py http://<mac-ip>:8123/<file>.ipk` — install by URL over SSAP.

On the TV, as root (the usual path):

- `dist/tv_update.sh` — download the newest `com.shashvat.launcher_*_all.ipk` from the Mac's HTTP
  server (`http://192.168.0.3:8123`), install it via `com.webos.appInstallService/dev/install`,
  refresh app icons, and relaunch.
- `dist/tv_install.sh <file.ipk>` — install one named IPK (no root needed).
- `dist/tv_icons.sh` — just refresh the app icons.

## The debug loop

- **`tools/tv-cdp.js`** — talks to the TV's Chrome DevTools on **port 9998**:
  `node tools/tv-cdp.js shot out.png` (screenshot), `metrics` (live layout numbers), `eval "<expr>"`,
  `console` (recent console messages), `css "<css>"` (inject CSS live), `targets`.
  Override the host/port/app with `TV_IP`, `TV_CDP`, `TV_APP`.
- **`tools/tvsh.py`** — run a shell command on the TV as root over Homebrew Channel's telnet service.
- **`tools/run_tv.py`** — run a shell command as root via `hbchannel.service/exec`.
- **`tools/probe_tv.py`** — register over SSAP and list installed apps.
- **`tools/read_beacons.py`** — decode the base64 beacons the root payload sends back to the Mac's
  temp HTTP server log.

Typical loop: edit `app/`, `tools/build_ipk.py`, `dist/tv_update.sh` on the TV, then
`node tools/tv-cdp.js shot` / `metrics` / `console` to see what changed.

## Boot & Home behaviour

Three independent mechanisms, each safe to remove on its own:

1. **Home key → Lumina** via **LG Input Hook** (`org.webosbrew.inputhook`). Key `773` (HOME) is
   bound in `/home/root/.config/lginputhook/keybinds.json`:
   `{"773":{"action":"launch","id":"com.shashvat.launcher"}}`.
2. **One-shot boot hook** — `/var/lib/webosbrew/init.d/60-tvl-launcher.sh` (from
   `rootrun/lumina-boot.sh`). Deliberately conservative: it waits for the app manager to answer,
   makes **one** launch attempt per boot (never a retry loop), and only takes over when the stock
   home (or nothing) is on screen — if you started Netflix during boot, it leaves you alone. It logs
   to `/tmp/lumina-boot.log`.
3. **Watchdog** — `rootrun/lumina-watchdog.sh`. Polls `getForegroundAppInfo` every 2 s and, when
   LG's own home appears (an app exited, Home fell through, a reboot finished), bounces straight back
   to Lumina, with a 4 s cooldown so it can't flap. It writes a pidfile
   (`/var/run/lumina-watchdog.pid`) so it never starts twice.

`dist/tv_push.sh` is the earlier one-shot that *also* moved the power-on slot
(`settingsservice` `general` `lastInputApp`/`physicalLastInputApp`) to the launcher; the current
setup leaves the power-on slot alone and relies on the boot hook + watchdog instead.

## Speed & privacy stack

- **Life's Good Without Spying** (`ooo.lew.lifesgoodwithoutspying`) — withdraws from LG's consent
  and "service" agreements and shuts down the associated collectors.
- **LG App Update Blocker** (`org.webosbrew.appupdateblocker`) — stops LG silently updating its own
  pre-installed apps.
- **Six masked background services disabled** via the **Glasshouse** dashboard API —
  `contentminer`, `uploadd`, `rdxd`, `remotelogger`, `nudge`, `camera` — toggled (reversibly) by
  `tools/glasshouse_services.py`, which reports the `MemAvailable` change before/after.
- **Quick Start+ off** (`option.quickStartMode: off`) so every power-on is a real boot and the boot
  hook actually runs.
- **Firmware update domains DNS-blocked** (via Glasshouse's ad-blocking `hosts` bind-mount).
- **Bluetooth disabler** (`pl.krzywro.webos-bluetooth-disabler`).

See `docs/HOMEBREW-HOOKS.md` for the exact boot hooks and how to remove each one, and
`docs/PENDING.md` for open items.

## Undo / unroot

- **`dist/tv_stop_launcher.sh`** — stop Lumina appearing on its own: removes the boot hook, reverts
  the power-on slot to Live TV, clears the Home keybind (`echo '{}' > .../keybinds.json`), closes the
  running instance, and prints verification.
- **`dist/tv_unroot.sh`** — return the TV to near-stock. **Not run automatically.** Run it on the TV
  as root only when you mean it. Order matters: it removes boot hooks and SSH keys *before* uninstall
  instructions, sets the power-on slot back to Live TV, restores Quick Start+, and lists the apps to
  uninstall from the TV's own app list (Homebrew Channel last, since that wipes root persistence).
  Its final option is a factory **Reset to Initial Settings**.
- **`dist/tv_wifi_revert.sh`** — if a power-on experiment breaks networking: revert the power-on slot,
  dump Wi-Fi/link state and the boot logs.

## Notes

- This is a **private repo** for one TV, so the TV's LAN address **`192.168.0.10`** (and the Mac dev
  machine's `192.168.0.3`, used for the port-8123 HTTP server) appear directly in the scripts. That is
  intentional and fine here; it would need scrubbing before this became public.
- No secrets are stored in the repo: no keys, tokens or credentials. The SSH key referenced by
  `tools/glasshouse_services.py` (`~/.ssh/webos_tv`) lives outside the tree, as do the `gh`/SSH
  credentials used to push.
- The launcher is ES5 on purpose — it must run in the TV's own web engine, and `app/js/*.js` uses no
  modern syntax.
